# Ejercicios en C++ 🚀

¡Hola! En este repositorio comparto mis códigos y prácticas desarrolladas en el lenguaje **C++**. 

## 📂 Contenido del proyecto
* **Estructuras de datos básicas (`struct`):** Modelado de objetos del mundo real y asignación de atributos dinámicos (ej. Gestión de datos de personas).
* **Fundamentos de programación:** Ejercicios prácticos aplicando condicionales, bucles y funciones lógicas.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** C++
* **Entorno de desarrollo:** Visual Studio Code
* **Compilador:** GCC / G++
